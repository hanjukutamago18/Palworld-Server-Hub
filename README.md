# Palworld-Server-Hub
Aplikasi ini dikembangkan untuk mempertemukan para pemain (player) dengan para pengelola Dedicated Server Palworld di Indonesia.

Tujuan utama platform ini adalah untuk memudahkan pemain dalam menemukan Dedicated Server yang sesuai dengan kriteria dan preferensi bermain mereka, sekaligus membantu para pengelola server dalam menjangkau audiens yang lebih luas guna membangun komunitas pemain yang aktif dan ramai.

Dengan adanya direktori status server secara real-time, pemain dapat melihat statistik pemain aktif, versi server, dan cara bergabung sebelum memutuskan untuk masuk ke dalam sebuah komunitas.
